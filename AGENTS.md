# AGENTS.md - SkillRoute India Engineering Guidelines

SkillRoute India is an AI-powered Career Navigator and Prerequisite Graph engine tailored to the Indian tech ecosystem and GCC (Global Capability Center) talent pipelines.

## Stack Overview
- **Backend:** Python 3.9+, FastAPI, Neo4j Python Driver, Gemini REST API, Pydantic v2, pytest.
- **Frontend:** React 19, Vite, TypeScript, Tailwind CSS, Plus Jakarta Sans, Material Symbols Outlined. Adapts Lumina SaaS styling from the preserved Stitch export, with working core screens and six labeled prototypes.
- **Database:** Neo4j AuraDB property graph with in-memory graph fallback for honest Demo Mode.

## Graph Schema Specifications
- **Nodes:**
  - `(:Role {id, title, category, summary, marketDemand, typicalExperience, tier})`
  - `(:Skill {id, name, category, description, estimatedHours, difficulty})`
  - `(:Resource {id, title, url, provider, type, is_free, duration, rating})`
- **Relationships:**
  - `(:Role)-[:REQUIRES {importance: 'Core'|'Recommended'|'Elective', level: 'Foundational'|'Proficient'|'Advanced'}]->(:Skill)`
  - `(:Skill)-[:DEPENDS_ON {strictness: 'Required'|'Recommended'}]->(:Skill)` (Prerequisite directed edge: A DEPENDS_ON B means B must be learned before A)
  - `(:Resource)-[:TEACHES {level: 'Beginner'|'Intermediate'|'Advanced'}]->(:Skill)`

## Mandatory Guardrails & Security Rules
1. **Parameterized Cypher Only:** Never concatenate user input or LLM output into Cypher queries. Always use `$params`.
2. **No LLM-Generated Cypher Execution:** Never execute Cypher generated by Gemini. Gemini operates strictly in an advisory role with grounded graph evidence injected by the backend service.
3. **No Silent Remote Seeding on Page Load:** Seeding Neo4j is only performed through the explicit idempotent CLI (`python -m backend.seed_cli --force`).
4. **Secret Protection:** Never expose `NEO4J_PASSWORD` or `GEMINI_API_KEY` to frontend responses or server logs. Only report connection boolean / masked status.
5. **Honest Demo Mode & Health Status:** When credentials are empty or disconnected, the backend returns `is_demo_mode: true` with a clear label. Never fake verified credentials or remote sync.
6. **Hackathon Neo4j Rubric Status:** Exact hackathon Neo4j product rubric requirements are PENDING from user, never officially verified. Never make unverified rubric claims.
